# Sales Follow-ups on Today

Base staging `aad370f1f`. Show stale quotes and open callbacks on Today. Reps see stale quotes on customers assigned to them and callbacks whose Team Board assignee is their user ID. Admins see the team queue, including unassigned work. These are Today display filters. Existing Team Board and database access rules govern the records.

- Use the current Call Lists reader for quotes untouched for at least 14 Chicago calendar days. Keep its active-farm, open-quote, and rep-scope rules. Honor access to Call Lists and Quotes. Rows show the owner, last customer interaction and exact quote link.
- Today's callbacks are open, nondeleted Team Board tasks linked to a customer or quote. Respect the corresponding page access. Sort by Chicago due day, with overdue first, and label due today, upcoming and undated. For each visible stale quote, link to the existing open callback even if it belongs to another assignee or is unassigned. A farm-level task remains a farm-level task.
- Schedule a to-do with the existing Quick Task form, linked to the exact quote. Prefill the customer's rep only when the directory shows that rep is active. Wait for the assignee list before saving to that rep. Freeze the form while saving, then reload callbacks after success. The Team Board assignee receives the ordinary assignment notification. Within the open form a retry uses the same task ID. A duplicate ID counts as success only when the stored task matches the attempted fields and creator.
- Independently load the quote and callback lists and use the source counts. Stale quotes use the RPC total before its row cap and appear only with Call Lists and Quotes access. Callbacks use exact paging; omit quote-linked or farm-linked rows whose respective page is denied. A failed list offers a retry. If supporting details fail, keep the core rows visible and offer a retry. Re-entering Today reloads both lists.
- Files in scope are OfficeCockpit, a sales section, a shared stale-quote reader used by Call Lists, the existing Quick Task form, and focused tests. No schema change. Treat the timestamp as the customer's last interaction across all quotes.
- The stale quote RPC scopes sales reps by `c.assigned_sales_rep = auth.uid()` even when the optional rep parameter is omitted. Scheduling rechecks recent callbacks linked to the visible quotes before opening the form. If a retry finds an earlier save with different fields, show the mismatch, close the form and refresh both lists. Closing an unconfirmed form also refreshes the lists to show a callback whose save may have reached Team Board.

Local Chromium proof used the disposable staging-based database and invented users. A rep saw overdue, due-today and upcoming tasks on a 390px phone. A failed stale-quote read left callbacks available. Retry showed the rep's 21-day-old quote. A simulated lost response after the database saved the callback yielded one exact quote-linked Team Board task after retry. Completing it removed it from Today on return. An admin saw another rep's callback and unassigned work. A driver could not open Today. No production access.

## Settled for Luna

- Team Board is an exempt route with both admin and sales rep access in `src/appPages.tsx`. ProtectedRoute does not apply a configurable page denial to that route. Today checks the permissionable customer, quote and Call Lists pages.
- `localToday()` in `src/lib/dateUtils.ts` delegates directly to `todayInBusinessTz()`, which formats the Chicago calendar day regardless of the device timezone.
