**What it does.**

The P&L earns commission by the share billed over the same invoices, so it earns exactly the posted profit after its discount (Taha, rule "b").

Locks only rows it moves, re-reads them, writes only those. A sale with no posted discount that never carried a standing-discount line is untouched (legacy rows; every sale on live while the M4 switch is off); one that did has its rows put back on the plain profit.
