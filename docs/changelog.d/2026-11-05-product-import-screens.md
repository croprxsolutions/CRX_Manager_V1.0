## 2026-11-05 — Bulk product import screen moves onto the safe save (WP-PM-10, screens)

The Products page's bulk import window now previews the file with `preview_product_import` and saves with `apply_product_setup` insert mode (live since 2026-11-05, PR #1486), instead of inserting rows directly. It reads the CSV with a real parser (quoted commas and multi-line notes keep their text), accepts only exact unit and container names, shows each spelling it fixed, refuses each bad row in plain English with the reason, flags duplicate SKUs or names (in the file or already in use) and other products with the same EPA number, shows the per-acre prices each row will get, and offers a template. The file saves all at once or not at all, once per preview, and rate columns are refused while Lock rates is on. No database change.
