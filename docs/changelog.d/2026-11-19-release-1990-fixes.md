## 2026-11-19 — Release v0.1.0 (#1990) fixes in our own migrations

- New migration `20270129160000_release_fixes_1990.sql` (not applied live; record in `docs/reference/migrations.d/`).
- Field-application invoices: a sent quote on a field billed per acre no longer sets the price of a chemical billed per unit on the grower's other field (the save and the preview on the invoice screen). Before, a $60/gal quote on a per-acre field could bill 10 gal $600 instead of the $300 list price.
- Split-bill invoices: the internal save helper can now be run only through its own save function, not by any API role.
- Stock unit: a stock-unit change is refused outside a READ COMMITTED transaction, so it cannot slip past a line or hold committed while it was running. The app already runs READ COMMITTED, and the product setup screen already refuses unit changes on saved products.
- Purchasing plan: an accepted booking whose only order was deleted counts again (its demand showed 0).
- Nightly quote expiry: takes an idempotency key and runs one sweep at a time, so an overlapping run sends no "booking past its date" alert twice (it runs only in READ COMMITTED, as the nightly job does).
- Proof: container prover `scripts/smoke/prove-release-fixes-1990-real-schema.mjs` (before and after for each fix; rollback restores every previous body). Not yet verified on staging.
