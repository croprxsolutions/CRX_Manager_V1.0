## 2026-11-05 — Product parents: group existing products through an approved proposal (PAR-2)

Migration `20261117120000_product_parent_proposals.sql` (pending apply). An admin can build a proposal that suggests which existing products are sizes of one product (same name once sizes are removed, same form, same EPA number), review each suggested group, and approve, hold or reject it. Nothing is grouped until an admin approves; anything that changed since the proposal was built refuses the approval. Approving copies the chosen category, use timings and rates onto every size, never an EPA number or label fact, and moves the sizes' brand lists onto the parent. While rates are locked, a group that would change a rate waits. The old per-size brand editor now refuses a grouped size. Screens come in a later PR. Proof: `scripts/smoke/prove-product-parent-proposals-real-schema.mjs`.
