Saves that leave the rates unchanged (including stray spaces in the suggested rate, and the seed/each rate unit that a new product takes from its inventory unit). Refused while locked. - New `preview_product_rate_correction(product, rate, unit)`: admin only, read-only; returns the tier 1–3 per-acre prices before and after a proposed correction, computed the way the save will compute them. The correction window shows it before the save button appears.
