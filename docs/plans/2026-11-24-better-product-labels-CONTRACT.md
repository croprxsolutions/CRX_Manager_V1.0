### Grouping and fixes

- Grouped brand creation uses `product_parent_brand_sources` to map old brand rows to the destination brand, including the existing distinction between active and retired brands. Within the grouping transaction, copy one agreed specimen and SDS into each destination and combine distinct supplemental entries. Identical supplemental entries collapse into one. A blank source has no opinion. Two different active specimen or SDS URLs for the same destination brand stop the whole grouping transaction. The refusal names the brand and document kind so an admin can correct or hide a wrong link on the standalone records, then retry.
- Preserve legacy document history, record where each copied link came from and carry one open report per matching destination link. The old report moves into history as carried. Retired brand variants retain their documents and reports for history. If the chosen variant and a retired variant agree on brand name, EPA number and manufacturer, the link can also follow the chosen variant. A hidden source stays in history and does not take part in carry-over. A link match uses the normalized URL and, for a supplemental link, state and expiry.
- Serialize every link write, report, hide and dismissal with the product or parent lock used by grouping. Refuse a standalone write after its scope changes. All four actions use version checks and keys bound to the actor and exact request.
- An admin may hide an incorrect link or close a false report with a reason. Hiding removes it from opening and the fix list and keeps the URL and history. Closing a false report leaves the link visible. These actions are explicit screen actions. Blank workbook cells never hide or clear a link.
- When moving a size between existing groups, the move preview and save refuse if corresponding active brands have different visible documents. The refusal names the brand and document kind. Mason confirmed this rule on 24 November 2026.
- Use document versions separate from brand edit versions. Verify current brand identity and scope on write. The workbook updates existing brands only and follows the existing per-tab preview and save pattern.
- Normalize the hostname for blocked-domain comparisons. Refuse credentials and malformed addresses. Use the same validation fixtures in browser and database. Open external links in a separate tab without opener access.
- Keep history for link changes, reports and resolutions. Show outstanding reports for current editable brands to active admins. Keep reporter identities and timestamps out of the staff link read. A database rollback can withdraw the write surface while retaining the records.
- Require the admin to hide old documents with a reason before changing a brand name, EPA registration or manufacturer. If a size move empties the old group, carry unresolved reports onto identical destination links with their original reporter and retain the transfer in history.
