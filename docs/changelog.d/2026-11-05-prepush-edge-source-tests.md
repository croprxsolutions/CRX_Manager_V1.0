## 2026-11-05 - Pushes run the tests that read a changed Edge Function

On PR #1515 a change to `supabase/functions/send-email/index.ts` broke `src/lib/sendEmailEdgeGateContracts.test.ts`, which string-matches the function source, and it surfaced only in CI because pre-push skips app tests when no app file changed. `.husky/pre-push` now asks `scripts/prepush-needs-build.mjs --edge-tests` for the vitest files under `src/` that name a changed `supabase/functions/<folder>` (or `_shared`) and runs only those (about 4 seconds for send-email's four). A failure blocks the push and names the files. Proof: a scratch commit touching send-email selected and ran four files and passed; with `sendEmailEdgeGateContracts.test.ts` made to expect a string absent from the source, the real hook exited 1 with "EDGE FUNCTION SOURCE TESTS FAILED" naming all four files. Tests: `scripts/prepush-needs-build.test.mjs`.
