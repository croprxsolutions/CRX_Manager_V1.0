A stated $0 price, a typed price, a price-later order line, an order line that still carries the product of a quote line the quote itself set at $0, invoice lines not priced from the tier, and an edit that re-sends a line with the same product and price are not refused. A price under one cent counts as $0. No data, grants on existing objects, policies or RPC bodies change.
