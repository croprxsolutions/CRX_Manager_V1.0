## 2026-11-04 — Setup workbook (WP-PM-11a-2, local candidate)

Local candidate migration `20261106160000_product_setup_workbook.sql`, not applied; it needs `20261106120000_product_rate_lock` (WP-PM-11a-1) first. Adds a "Setup Workbook" button on the Products page (admins, wide screens). It downloads one spreadsheet, separate from the price sheet, with a **Setup** tab (product details: name, SKU, category, manufacturer, container size and type, EPA number, RUP, signal word, REI, PHI, label max rate and unit, use timings, notes) and a **Rates** tab (rate per acre, rate unit, suggested rate, with the current tier 1–3 per-acre prices for reference). After an upload, each tab shows a preview of every change: field by field for Setup, and rates with tier 1–3 per-acre prices before and after for Rates. Each tab has its own Confirm, and nothing saves until it is pressed. A row someone else changed after the download is refused by product name, and each tab saves all its rows or none. The Setup tab never writes prices, cost, rates, vendor, active status, form, stock unit, pack size or container unit. Rates save only through `set_product_rates`, so the "Lock rates" switch refuses a Rates upload while locked; the Setup tab still saves. New products cannot be added from the workbook yet (WP-PM-10 adds insert mode to the same Setup save). Proof: `scripts/smoke/prove-product-setup-workbook-real-schema.mjs`.
