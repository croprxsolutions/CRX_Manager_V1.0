## 2026-11-26 - Staging Maps drawing proof

The staging build includes a disposable, sign-in-protected drawing page for synthetic polygons. It can switch between USDA and Mapbox, simulate an outage, and retry while the user sketches or drags a vertex. The page shows the active picture's credits. Its saved draft is scoped to the browser tab. The normal app build and shared map engine are outside this proof.
