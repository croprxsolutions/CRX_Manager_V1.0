## 2026-11-04 — Setup workbook, database part (WP-PM-11a-2, local candidate)

Local candidate migration `20261107080000_product_setup_workbook.sql`, not applied; it needs `20261107060000_product_rate_lock` (WP-PM-11a-1) first. Adds the three admin-only database functions behind the setup workbook, a spreadsheet separate from the price sheet with a Setup tab (product details) and a Rates tab: `get_product_setup_workbook` (the download, with a per-row fingerprint), `preview_product_rates` (each rate change with tier 1–3 per-acre prices before and after, computed the way the save computes them) and `apply_product_setup` (the Setup tab's all-or-nothing save; a row someone else changed since the download is refused by product name). The Setup save never writes prices, cost, rates, vendor, active status, form, stock unit, pack size or container unit; Rates save only through `set_product_rates`, so the "Lock rates" switch applies. Nothing calls these yet: the Products page's Setup Workbook button lands in a follow-up PR once this is live. New products cannot be added from the workbook yet (WP-PM-10 adds insert mode to the same Setup save). Proof: `scripts/smoke/prove-product-setup-workbook-real-schema.mjs`.
