# Sales Follow-ups on Today

Base staging `aad370f1f`. Show stale quotes and open callbacks on Today. Reps see stale quotes on customers assigned to them and callbacks whose Team Board assignee is their user ID. Admins see the team queue, including unassigned work. These are Today display filters. Existing Team Board and database access rules govern the records.

- Use the current Call Lists reader for quotes untouched for at least 14 Chicago calendar days. Keep its active-farm, open-quote, and rep-scope rules. Honor access to Call Lists and Quotes. Rows show the owner, last customer interaction and exact quote link.
- Today's callbacks are open, nondeleted Team Board tasks linked to a customer or quote. Respect the corresponding page access. Sort by Chicago due day, with overdue first, and label due today, upcoming and undated. A quote-linked task can be opened from its stale quote when it is in the current callback scope. A farm-level task remains a farm-level task.
- Schedule a to-do with the existing Quick Task form, linked to the exact quote. Prefill the customer's rep only when the directory shows that rep is active. The existing save disables repeat clicks while pending, and reports success to Today so callbacks reload. The Team Board assignee receives the app's ordinary assignment notification. An ambiguous retry has the existing Quick Task behavior.
- Independently load the quote and callback lists and use the source counts. Stale quotes use the RPC total before its row cap and appear only with Call Lists and Quotes access. Callbacks use exact paging; omit quote-linked or farm-linked rows whose respective page is denied. A failed list offers a retry. Re-entering Today reloads both lists.
- Files in scope are OfficeCockpit, a sales section, a shared stale-quote reader used by Call Lists, the existing Quick Task form, and focused tests. No schema change. Treat the timestamp as the customer's last interaction across all quotes.

Local Chromium proof used the disposable staging-based database and invented users. A rep saw overdue, due-today and upcoming tasks on a 390px phone. A failed stale-quote read left callbacks available. Retry showed the rep's 21-day-old quote, and saving yielded one exact quote-linked Team Board task. Completing it removed it from Today on return. An admin saw another rep's callback and unassigned work. A driver could not open Today. No push or production access.
