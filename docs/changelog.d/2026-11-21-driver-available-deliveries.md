## 2026-11-21 - #2018: drivers can list open deliveries and take one for themself (database part)

- Migration `20270204120000_driver_available_deliveries.sql` adds `get_available_deliveries_for_driver()`: an active driver not denied the Deliveries page only (everyone else refused) gets every open delivery (unassigned, scheduled, not deleted), soonest first, with only id, number, date, customer and top farm group. Mason decided 2026-11-21 that every driver may see these. The deliveries read rule is unchanged.

Refresh the list." (one already theirs, with a fresh key: "already assigned to you") Two drivers taking one delivery at once: the first gets it, the second is refused. A retry with the same key by the same caller for the same request (any role) now returns its stored result before the body runs (for a driver, only while the delivery is still theirs; otherwise "already taken or changed"), so a driver's retry after a lost reply replays instead of being refused. Admin and sales rep authority is unchanged.

Every driver button works through server functions, unchanged. Admin and sales rep unchanged.
