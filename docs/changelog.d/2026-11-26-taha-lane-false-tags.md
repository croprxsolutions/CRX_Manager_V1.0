## 2026-11-26 — Fewer false Taha-lane tags

Mason's answers to a survey of PRs the Taha-lane rule tagged since 2026-11-04, as changed by Taha's review of #2639:

- **#2381** (parent EPA): the customer year-end summary functions stay Taha's (they are a money statement); #2381 goes through on Mason's code.
- **#2267** (Piksi grams): a migration named for a product's units that also converts the product's own units in `public.products` may lock tables and UPDATE only the unit columns (`unit_size`, `rate_unit`) of order and quote lines, scoped by a WHERE. A line quantity, a price or any other change to those tables still counts, and so does every other lane table and function. An honest-mistake net, accepted by Mason.
- **#2451** (office menu): a change to one of Taha's screens that only edits words people read no longer counts. Words are JSX text, comments, label-like JSX attributes (`label="…"`) and the labels of menu and tab entries (a `path`, `to`, `href` or `key` on the same line); any other `label: '…'` in an object is code, since the app may save it. No money screen in Taha's lane gets the words-only pass (his call): every named lane file (order, customer, A/R, report and sale-money screens), invoice, payment, prepay, A/R, commission-payment and month-end-close pages, the bill split and commission split editors, `src/components/invoices/`, `prepay/` and `statements/`, `src/lib/invoice*`, `statement*` and `customerStatement*`, `*Pdf.ts` and `*Email.ts`. So #2451 (Prepay and the finance dashboard) is still his.
- **Delivery completion** stays Taha's.
- **The `taha-ready` bot** no longer labels or pings Taha for a PR whose only lane files are the lane block's launchers and settings (`merge-guard-launcher`, `prompt-router`, `migration-apply-guard`, `settings.json`, `hooks.json`); a change to `pr-merge-guard.mjs` or the Codex `production-action-guard.mjs` (they call his lane gate) or to the block's libraries (`taha-lane-lib.mjs`, `migration-landing-gate-lib.mjs` and the like: what his lane and hold are) still goes to him, and on a hotfix into `main` the `.github/` files he owns count alongside the lane files, and back-merges of `main` are judged like any PR. Mason's code is still needed to merge them.
- The PR file list now carries patches only for edited app code files, and the Codex merge gate reads `gh` output up to 16 MiB (like the Claude gate), so a large PR is far less likely to be refused as unreadable (a list past 16 MiB still is: fail closed).
