## 2026-10-29 - Sol runs once before the PR; CodeRabbit is optional

Mason is leaving CodeRabbit. Money PRs no longer need a CodeRabbit review: the merge gates, the migration landing gate and the Sol pre-flight only ask for one when a PR carries the `needs-coderabbit` label. Sol now runs on the computer before the PR is opened (the Sol pre-flight no longer refuses when no PR exists), and both merge gates (Claude's `pr-merge-guard`, Codex's `production-action-guard`) accept a clean Sol proof under 24 hours of the PR's head or of an earlier commit on its branch that is not already in main, so later fixes merge without a second Sol run. Accepted risk: commits pushed after the Sol review get no Sol look. GitHub's own rules are unchanged (it requires only CI and the Vercel build). Updated `AGENTS.md`, `.claude/commands/ship.md` and `scripts/check-agent-guidance.mjs`.
