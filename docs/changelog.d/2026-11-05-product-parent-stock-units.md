## 2026-11-05 — Product parents: a seed or each parent's sizes share one stock unit (PAR-1 follow-up)

Migration `20261110150000_product_parent_stock_units.sql` (applied live 2026-11-05). A seed or each parent's rate is per stock unit, so adding or moving in a size stocked in a different unit (a Unit size under a Lb parent) is now refused by name instead of giving the two sizes one number in two units. Liquid and dry parents are unchanged. A size moved under a parent now stores the parent's EPA number spelling, as an added size already did, and a Rates-tab upload that resends a parent's current rates skips that parent instead of refusing the whole upload. Proof: `scripts/smoke/prove-product-parents-real-schema.mjs`.
